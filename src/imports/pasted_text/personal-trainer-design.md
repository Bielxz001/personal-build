Crie o design completo de um site/app mobile-first para um Personal Trainer jovem, com aproximadamente 27 anos, voltado para um público jovem e conectado, que busca melhorar o físico, performance, disciplina e qualidade de vida.

O projeto deve transmitir uma imagem de PERSONAL TRAINER MODERNO, TECNOLÓGICO, JOVEM, CONFIANTE E DESCONTRAÍDO.

Não quero um visual genérico de academia. Quero uma identidade visual forte, moderna e memorável, que pareça um produto digital profissional e tenha potencial para posteriormente ser desenvolvido em React Native.

### DIREÇÃO VISUAL

Utilize uma estética premium esportiva, combinando:

* Tipografia grande e impactante
* Blocos sólidos de cor
* Alto contraste
* Cards modernos
* Bordas levemente arredondadas
* Elementos geométricos
* Números grandes
* Microinterações
* Espaços negativos bem utilizados
* Fotos do próprio Personal Trainer como elemento principal da identidade
* Composição editorial semelhante a campanhas modernas de fitness
* Visual tecnológico sem parecer excessivamente futurista

Evite completamente:

* Visual de academia antiga
* Excesso de preto com vermelho
* Gradientes exagerados
* Ícones genéricos de musculação
* Aparência de template pronto
* Excesso de elementos na tela
* Design corporativo tradicional

### PALETA

Utilize uma paleta baseada em cores sólidas e alto contraste.

Sugestão principal:

* Preto profundo / quase preto como base
* Branco para textos
* Verde-limão ou verde neon como cor de destaque
* Cinza escuro para superfícies secundárias

A cor de destaque deve aparecer em:

* Botões
* Números
* Pequenos detalhes
* Indicadores
* Links
* Elementos de interação

A paleta deve transmitir energia, performance e juventude.

### HOME / HERO

Crie uma primeira seção extremamente impactante.

Utilize uma fotografia grande do Personal Trainer treinando ou em uma pose atlética.

A composição deve ter:

"SEU CORPO.
SEU RITMO.
SEU RESULTADO."

como headline principal ou uma variação semelhante.

Adicionar uma frase curta explicando a proposta do profissional.

Exemplo:

"Treinamento personalizado para quem quer evoluir de verdade."

Adicionar dois CTAs:

"COMEÇAR AGORA"

"CONHECER MEU MÉTODO"

O botão principal deve ter bastante destaque.

A fotografia deve ocupar uma grande parte da tela e conversar visualmente com os elementos tipográficos.

Adicionar pequenos elementos como:

+500 ALUNOS
5 ANOS DE EXPERIÊNCIA
100% PERSONALIZADO

Esses números devem aparecer de forma visualmente interessante.

### NAVEGAÇÃO

Criar uma navbar minimalista e moderna.

Itens:

INÍCIO
SOBRE
MÉTODO
TREINOS
RESULTADOS
CONTATO

Adicionar um botão destacado:

"QUERO TREINAR"

No mobile, transformar a navegação em menu hamburger moderno.

### SEÇÃO "SOBRE"

Criar uma seção apresentando o Personal Trainer.

Utilizar uma fotografia dele de maneira editorial, podendo ocupar uma área grande da tela.

Adicionar:

"MAIS QUE TREINO."

como título.

Texto curto apresentando sua filosofia de treinamento, personalidade e abordagem.

A seção deve transmitir proximidade e autenticidade, evitando linguagem excessivamente corporativa.

Adicionar pequenas informações:

27 ANOS
PERSONAL TRAINER
PERFORMANCE
TREINAMENTO PERSONALIZADO

### SEÇÃO MÉTODO

Criar uma seção chamada:

"MEU MÉTODO"

Apresentar o processo de trabalho em 3 ou 4 etapas.

01 — AVALIAÇÃO
02 — PLANEJAMENTO
03 — TREINAMENTO
04 — EVOLUÇÃO

Cada etapa deve possuir um card visualmente forte.

Utilizar números grandes e tipografia marcante.

### SEÇÃO TREINAMENTOS

Criar cards para diferentes objetivos:

HIPERTROFIA
EMAGRECIMENTO
CONDICIONAMENTO
PERFORMANCE
TREINAMENTO PERSONALIZADO

Cada card deve possuir uma imagem ou composição visual própria.

Ao passar o mouse, os cards devem possuir uma sensação de interação.

### SEÇÃO RESULTADOS

Criar uma seção visualmente forte para depoimentos e resultados dos alunos.

Utilizar fotos de transformação quando disponíveis.

Criar cards de depoimentos com:

Nome
Objetivo
Depoimento

Adicionar métricas visualmente interessantes:

* KG PERDIDOS
* MASSA MUSCULAR
* PERFORMANCE
* CONSISTÊNCIA

Não exagerar nos números; a seção deve parecer real e confiável.

### SEÇÃO GALERIA

Criar uma galeria visual mostrando o Personal Trainer treinando, orientando alunos e trabalhando.

Utilizar um layout assimétrico e editorial.

Não utilizar uma simples grade de imagens.

Misturar:

* Fotos grandes
* Fotos menores
* Textos
* Números
* Espaços vazios

Criar uma sensação semelhante a uma campanha de marca esportiva.

### SEÇÃO CTA

Criar uma seção final extremamente impactante.

Headline:

"PRONTO PARA MUDAR O JOGO?"

Texto curto:

"Seu próximo nível começa com o primeiro treino."

Botão:

"COMEÇAR MEU TREINAMENTO"

Adicionar uma foto do Personal Trainer integrada ao layout.

### FOOTER

Criar footer minimalista contendo:

Logo/nome do Personal Trainer
Instagram
WhatsApp
Contato
Localização
Links rápidos

Adicionar uma frase curta de identidade da marca.

### ANIMAÇÕES E EXPERIÊNCIA

O design deve ser pensado para posteriormente receber animações de scroll.

Planejar visualmente elementos que possam:

* Entrar suavemente durante o scroll
* Fazer fade-in
* Subir da parte inferior
* Possuir parallax nas imagens
* Ter números animados
* Fazer cards aparecerem sequencialmente
* Ter pequenas interações nos botões
* Possuir transições suaves entre seções

As animações devem ser modernas e discretas, sem prejudicar performance.

### RESPONSIVIDADE

Criar versões:

Desktop
Tablet
Mobile

O mobile deve ser tratado como uma experiência própria, e não simplesmente como uma versão reduzida do desktop.

Priorizar:

* Tipografia
* Fotos
* CTAs
* Navegação
* Cards
* Espaçamento
* Legibilidade

### IDENTIDADE

Criar também uma identidade visual simples para o Personal Trainer.

Sugira:

* Nome/marca
* Logotipo tipográfico
* Monograma ou símbolo minimalista
* Tipografia principal
* Tipografia secundária
* Paleta de cores
* Estilo fotográfico
* Estilo de botões
* Estilo dos cards

O resultado final deve parecer uma marca pessoal forte.

### IMPORTANTE

Quero que o resultado tenha aparência de um produto desenvolvido por uma agência de design moderna.

A inspiração deve estar entre:

NIKE + FITNESS APP + PERSONAL BRAND + STARTUP DE TECNOLOGIA.

Porém, NÃO copie nenhuma dessas marcas.

Crie uma identidade original.

Priorize impacto visual, personalidade, fotografia, tipografia e experiência.

O resultado precisa fazer uma pessoa entrar no site e pensar:

"Esse Personal Trainer parece profissional, jovem e diferente dos outros."

Prepare o design pensando que posteriormente ele será implementado utilizando React Native, portanto utilize componentes e padrões de interface que possam ser reproduzidos em código.
